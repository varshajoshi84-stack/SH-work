# PTP Reliability Analysis

This project analyzes Promise to Pay (PTP) reliability using Python, Pandas, and Matplotlib.

## Features
- Categorizes outcomes (Kept, No Payment, Late but Full, Partial, etc.)
- Calculates reliability scores
- Visualizes results with charts

## How to Run
1. Install requirements:
pip install -r requirements.txt
2. Run the script:
python ptp_analysis.py
## Example Output
- Reliability Score: 60%
- Charts showing breakdown of statuses
